# 작업 기록

my-develop-wiki의 작업 이유와 검증 근거를 찾는 안내입니다. 저장소 소개는 루트 [README.md](/README.md)에 두며, 이 파일에 개별 기록 목록을 누적하지 않습니다.

- 작성·조회 기준: [20_wiki/operations/worklog-writing-guide.md](/20_wiki/operations/worklog-writing-guide.md).
- 개인 위키 적용: [20_wiki/operations/log-writing-guide.md](/20_wiki/operations/log-writing-guide.md).
- 위치: `docs/worklog/YYYY-MM/YYYY-MM-DD-<주제>-<식별자>.md`. PR/MR 또는 독립 변경 하나당 기록 하나가 기본입니다.
- 실제 변경·채택된 결정·새 검증 결과·후속 조치가 필요한 발견·저장 요청만 기록합니다. 같은 변경의 미병합 기록을 재사용합니다.
- 과거 맥락은 `scope`·`topics`·`code_paths`와 본문 문서명으로 찾습니다. 관련 본문과 이전·후속 기록을 읽고, 현재 지침·코드와 대조합니다.
- 2026-09-23 기존 단일 로그 6항목을 사건 날짜 기준 월별 파일로 이관하고 구버전 파일을 삭제했습니다. 과거 기록도 이 폴더에서 날짜·주제·식별자로 검색합니다.
- 이관 기록의 생성일은 이관일, 파일명 날짜는 사건 날짜입니다. 기간 기록은 시작일을 사용합니다. 과거 기록에 새 작업을 이어 쓰지 않습니다. 검색이 부족하면 연결된 `/10_raw/` 원문을 확인합니다.
- 기록만 바꾸면 버전은 유지합니다. 규칙·구조 변경의 버전은 같은 작업에서 확정합니다. README·index에 기록 목록을 추가하지 않습니다.
